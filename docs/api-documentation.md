# DayMark API Documentation

## 1. Introduction

DayMark uses a RESTful API to connect the React frontend with the Node.js and Express backend.

The API handles:

- Authentication
- User profiles
- Activities
- Activity logs
- Goals
- Dashboard data
- Analytics
- Calendar data
- Notifications
